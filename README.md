## 🎯 Problem Statement & Vision

Over **1.5 million engineering students** graduate in India annually across Tier-1, Tier-2, and Tier-3 institutions. Despite high motivation, engineering undergraduates face systemic roadblocks:

1. **Uncertain Career Trajectories:** High confusion deciding between Full Stack Development, AI/Machine Learning, Data Science, and Data Engineering during 2nd and 3rd year.
2. **Placement Cutoff Ambiguity:** Vague cutoffs for Day-1 product companies vs. mass recruiters (CGPA criteria, DSA volume, system design depth).
3. **Branch-to-Tech Friction:** Non-circuit branches (Mechanical, Civil, Chemical, Electrical) lack clear roadmaps to pivot into software engineering without dropping academic CGPA.
4. **Generic & Unrealistic Roadmaps:** Online tutorials and 200-hour video courses fail to scale down to a student's realistic weekly availability (e.g., 10–15 hrs/week alongside semester exams).
5. **Unverified Skill Confidence:** Resumes stuffed with unverified technologies that crumble in technical interviews.

**Career Path Simulator** bridges this gap. By combining student academic standing, realistic study hours, diagnostic technical assessments, and Google Gemini AI, it generates tailored, side-by-side engineering trajectories, an ATS resume, and a personalized 30-day action sprint.

- **Parchment & Spellbook Visuals:** A 3D perspective animated tome featuring rich leather bindings, celestial particle auras, floating arcane code runes, and realistic turning parchment pages.
- **Multi-Phase Sequencing:**

  2. 🧠 **AI/ML Engineer** (PyTorch, Scikit-learn, LLMs, Computer Vision, MLOps)

  $$\text{matchScore} = \text{clamp}\left(\text{round}\left(\text{base} + (98 - \text{base}) \times \frac{\text{progress} - \text{baseProgress}}{1 - \text{baseProgress}}\right), 0, 98\right)$$

- **First 30 Days Action Plan:** 4-week structured sprint calibrated strictly against the student’s weekly available study hours.
- **Curated Free Resources:** Direct links to roadmap.sh, freeCodeCamp, CS50, Kaggle Learn, NPTEL, fast.ai, and official documentation.

  - **Modern Tech ATS:** Clean sans-serif, high-density layout optimized for applicant tracking systems.
  - **Classic Ivy Engineering:** Traditional serif layout favored by core engineering and academic committees.

## 🔌 API Specification

All backend endpoints are implemented in both **Express (`server.ts`)** and **FastAPI (`api/index.py`)**.

### 1. `GET /api/health`
Checks server status and reports Gemini configuration.
```json
{
  "status": "healthy",
  "gemini_configured": true,
  "model": "gemini-3.8-flash"
}
```

### 2. `GET /api/sample`
Returns the resilient sample dataset containing the 4 pre-computed paths and question sets.

### 3. `POST /api/simulate`
Generates or retrieves tailored trajectories for a student profile.
- **Request Body:** `StudentProfile` (name, branch, cgpa, hoursPerWeek, skills, interests...)
- **Response:**
```json
{
  "fallback": false,
  "generatedFor": "Aarav Sharma",
  "paths": [ /* Full Stack, AI/ML, Data Science, Data Engineering */ ],
  "full_stack": { "matchScore": 78, "roleTitle": "Full Stack Web Developer", ... },
  "ai_ml": { "matchScore": 62, "roleTitle": "AI / ML Engineer", ... },
  "data_science": { "matchScore": 71, "roleTitle": "Data Scientist", ... },
  "data_engineering": { "matchScore": 84, "roleTitle": "Data Engineer", ... }
}
```

### 4. `POST /api/readiness/questions`
Fetches technical diagnostic questions, with optional filtering by programming language or role.
- **Request Body:**
```json
{
  "skills": ["Python", "SQL"],
  "language": "Python",
  "path_id": "full_stack"
}
```
- **Response:** Array of `QuizQuestion` objects with question text, options, and explanations.

### 5. `POST /api/readiness/evaluate`
Evaluates submitted quiz answers, calculates skill scores, and returns updated levels.
- **Request Body:**
```json
{
  "profile": { /* StudentProfile */ },
  "answers": [
    { "questionId": "py-1", "selectedOptionIndex": 1 },
    { "questionId": "py-2", "selectedOptionIndex": 2 }
  ]
}
```
- **Response:**
```json
{
  "skillScores": [
    {
      "skill": "Python",
      "score": 4.5,
      "previousLevel": "Beginner",
      "adjustedLevel": "Intermediate",
      "verified": true,
      "feedback": "Demonstrated solid grasp of Python sequences and hash structures."
    }
  ],
  "summary": "Skill readiness verified across submitted diagnostic questions."
}
```

### 6. `POST /api/roadmap/adjust`
Recalculates milestone statuses across career paths based on newly verified skills.

### 7. `POST /api/mentor`
Engages the placement mentor with contextual advice and suggested follow-up queries.
- **Request Body:**
```json
{
  "profile": { /* StudentProfile */ },
  "activePathId": "full_stack",
  "history": [
    { "role": "user", "content": "How do I get my first internship?" }
  ]
}
```

### 8. `POST /api/resume/polish`
Transforms profile details into polished executive summaries and quantified project bullet points.

## 🚀 Getting Started & Local Setup

### Prerequisites
- **Node.js:** v18.0.0 or higher
- **npm:** v9.0.0 or higher (or **Bun** v1.0+)
- *(Optional for Python Vercel runtime)*: Python 3.10+

### Installation Steps

1. **Clone the repository:**
   ```bash
   git clone <repository-url>
   cd career-path-simulator
   ```

2. **Install Node.js dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   ```bash
   cp .env.example .env
   ```
   *Note: Adding a Gemini API key is optional. The app operates with 100% feature parity using resilient offline mock data if no key is supplied.*

4. **Start the Development Server:**
   ```bash
   npm run dev
   ```
   Open your browser and navigate to `http://localhost:3000`.

5. **Type Checking & Linting:**
   ```bash
   npm run lint
   ```

6. **Production Build:**
   ```bash
   npm run build
   ```

## 🌐 Deployment Guide

### Option 1: AI Studio / Google Cloud Run (Full-Stack Container)
The application comes pre-configured with `server.ts` as the primary entry point:
```bash
npm run build
npm start
```
The server serves compiled static Vite assets from `/dist` while hosting all `/api/*` endpoints.

### Option 2: Vercel Serverless (React SPA + Python FastAPI)
1. Install the Vercel CLI:
   ```bash
   npm i -g vercel
   vercel
   ```
2. The included `vercel.json` automatically connects the frontend build and routes `/api/*` requests to `api/index.py`.
3. Add `GEMINI_API_KEY` in your Vercel Project Settings if using live Gemini generation.

### Option 3: Docker Container
```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```

## 🛡️ Resilience & Fallback Architecture

To ensure zero downtime during student presentations, hackathons, or campus interviews:

1. **Dual-Backend Support:** Works seamlessly with either the Node.js Express server or the Python FastAPI runtime.
2. **25-Second Timeout Guard:** All AI generation calls are bounded by abort controllers and an automatic retry mechanism.
3. **Structured Schema Validation:** Automatically extracts and parses JSON payloads, stripping away extraneous markdown fences.
4. **Instant Offline Fallback:** If the network is unavailable, the Gemini quota is exceeded, or no API key is provided, the application loads `/data/sample_outputs.json` with zero UI disruption.
5. **Interactive Demo Mode:** A dedicated switch in the navigation bar lets users explicitly toggle between live API calls and offline mock data.
